#Second-Hand Book Exchange#


Course: CSE115L
Section: 7
Semester: Fall 2026


## 1. Project Description
This project is a simple information management system written in C. It helps a user to sell a second hand book.
The user can list a book, ask for a fair resale price, record a sale, and see a report of all the books listed.


The program has 7 menu options:
1. List a Book: The user enters the book code, original price, age, and condition grade (1 to 3). This option also checks
the input validations.

2. Quote a Resale Price: The program calculates the resale price and shows the full book information.
  
3. Record a Sale: The program marks the book as sold. It will not let the same book be sold twice.

5. Stock Value Report: The program shows how many books were entered and the running total of their resale prices.
  
9. Exit: The program says thank you and closes.
